# MLB / KBO / NPB 전력 분석 프레임워크

야구 경기 결과 예측을 위한 전체 변수 맵. 가중치는 일반적인 경기 기준이며, 시리즈/시즌 컨텍스트에 따라 조정 필요.

## 가중치 요약

| 영역 | 가중치 | 비고 |
|---|---|---|
| 선발투수 | 40–50% | 가장 큰 변수 |
| 불펜 | 15–20% | 후반전 결정력 |
| 타선 | 15–20% | 종합 화력 |
| 수비 | 5–10% | 포수 프레이밍 주의 |
| 구장 효과 | 가변 | O/U에 결정적 |
| 날씨 | 가변 | 바람·온도 핵심 |
| 일정/피로 | 보정값 | 백투백·이동 |
| 심리/컨텍스트 | 보정값 | 동기부여 |
| 심판 | 숨겨진 변수 | 스트라이크존 |

---

## 1. 선발투수 (가중치 40–50%)

가장 중요. 한 경기 흐름의 절반 이상을 결정.

### 1.1 기본 스탯
- **ERA** (평균자책점) — 운빨 섞임
- **FIP** (수비 무관 평균자책) ⭐ 진짜 실력
- **xFIP** (홈런 정규화) ⭐⭐ 더 정확
- **SIERA** — 가장 정교한 지표
- **WHIP** (이닝당 출루)
- **K/9, BB/9, HR/9**
- **K-BB%** (삼진-볼넷 비율)

### 1.2 구질별 데이터 (Statcast)
- 평균 구속 (최근 5경기 vs 시즌)
- 회전수 (RPM)
- 무브먼트 (수직 / 수평)
- 익스텐션
- 릴리스 포인트 일관성
- 헛스윙률 (Whiff%)
- 컨택률 vs 강타구율

### 1.3 최근 폼
- 최근 3경기 ERA / FIP
- 최근 5경기 추세 (개선 / 악화)
- 마지막 등판 투구수 (피로도)
- 휴식일 (4일 / 5일 / 6일+)

### 1.4 상대 매치업
- 통산 vs 해당 팀 성적
- 우타자 vs 좌타자 OPS 허용
- 해당 팀 우 / 좌타 비율
- 해당 팀 K% vs BB%

### 1.5 환경
- 홈 / 원정 ERA 차이
- 낮 / 밤 경기 성적
- 잔디 / 인조잔디 차이

### 1.6 숨겨진 변수
- 시즌 누적 투구 이닝 (후반 피로)
- 부상 복귀 후 경기 수
- 트레이드 직후 / 이적 적응
- 슬럼프 vs 호조 시그널

---

## 2. 불펜 (가중치 15–20%)

### 2.1 팀 전체
- 불펜 ERA / FIP
- 불펜 WHIP
- 리드 시 승률
- 동점 시 승률

### 2.2 개별 투수
- 마무리투수 최근 폼
- 셋업맨 컨디션
- 좌완 스페셜리스트 가용성

### 2.3 피로도 ⭐ 중요
- 최근 3일 등판 횟수
- 어제 경기 투구수
- 연투 가능 여부
- 불펜 워크로드 (시즌 누적)

### 2.4 시리즈 컨텍스트
- 시리즈 1차전 불펜 소진 여부
- 내일 휴식일 여부

---

## 3. 타선 (가중치 15–20%)

### 3.1 팀 기본
- **팀 wRC+** ⭐ 가장 좋은 종합 지표
- wOBA (출루+장타 종합)
- ISO (순장타력)
- BABIP (운빨)
- 득점 / 경기

### 3.2 vs 투수 유형
- 좌투 상대 OPS
- 우투 상대 OPS
- 파워 투수 (K 많은) 상대 성적
- 컨트롤 투수 상대 성적

### 3.3 최근 폼
- 최근 10경기 득점
- 최근 10경기 OPS
- 연속 안타 / 홈런

### 3.4 라인업 변동 ⭐⭐ 중요
- 주전 결장 (휴식 / 부상)
- 라인업 순서 변경
- 대타 / 선발 투입

### 3.5 스플릿
- 홈 / 원정 타격
- 낮 / 밤 경기
- vs 좌투 / 우투
- 득점권 타율 (RISP)

---

## 4. 수비 (가중치 5–10%)

- 팀 **DRS** (수비 런 절감)
- 팀 **UZR**
- 에러율
- 더블플레이 변환율
- 외야 수비 범위
- **포수 프레이밍** ⭐ 의외로 중요 (투수 결과에 직접 영향)
- 도루 저지율

---

## 5. 구장 효과 (Park Factors)

### 홈런 친화도
- 쿠어스필드 (콜로라도) — 극도 타자 친화
- 양키 스타디움 — 좌타 홈런
- 펫코파크 (샌디에이고) — 투수 친화

### 구장별 변수
- 좌 / 우 펜스 거리
- 펜스 높이
- 파울 영역 크기
- 잔디 / 인조잔디
- 고도 (덴버 = 공 더 멀리)
- 외야 모양

> O / U (오버 / 언더) 베팅에 결정적 영향.

---

## 6. 날씨 ⭐ 의외로 큼

### 6.1 바람 (가장 중요)
- 풍향: 외야로 → 홈런↑ / 내야로 → 홈런↓
- 풍속: 10mph+ = 큰 영향
- 좌 / 우 측풍

### 6.2 온도
- 더운 날 (85°F+): 공 더 멀리 → 오버
- 추운 날 (50°F-): 공 안 감 → 언더
- 야간 vs 주간

### 6.3 습도
- 습한 날: 공 무거워짐 → 언더
- 건조한 날: 공 잘 날아감 → 오버

### 6.4 기타
- 비 (지연 / 취소 위험)
- 안개 (드물지만)
- **돔구장**: 환경 통제됨 — 변수 제거

---

## 7. 일정 / 피로도

### 7.1 팀 컨디션
- 백투백 (어제 경기 여부)
- 시리즈 N차전
- 원정 연속 일수
- 시차 (서부 → 동부 = 손해)
- 이동 거리

### 7.2 스케줄
- 다음 휴식일까지
- 최근 7일 경기 수
- 더블헤더 여부

---

## 8. 심리 / 팀 컨텍스트

### 8.1 팀 상황
- 연승 / 연패
- 플레이오프 경쟁 (모티베이션)
- 시즌 말 vs 초반
- 트레이드 데드라인 영향
- 감독 교체 직후 (반등 효과)

### 8.2 선수 컨텍스트
- FA 계약 앞둔 선수 (동기부여)
- 부상 복귀
- 첫 빅리그 경기
- 친정 팀 상대 (감정적)
- 기록 추격 중

### 8.3 라이벌리
- 디비전 라이벌
- 시즌 시리즈 전적

---

## 9. 심판 ⭐ 숨겨진 변수

### 홈플레이트 심판
- 스트라이크존 크기 (좁음 / 넓음)
- K% 평균 (심판마다 다름)
- 좌 / 우 일관성
- 리뷰 콜 성향
